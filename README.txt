ACHADINHOS

Arquivos:
index.html = loja
produto.html = detalhes do produto
admin.html = painel para cadastrar categorias/produtos
style.css = visual
script.js = loja
produto.js = detalhes
admin.js = painel

API usada:
https://achados.onrender.com

Para publicar:
1. Crie um novo repositório no GitHub, por exemplo achadinhos-site.
2. Envie estes arquivos.
3. No Render, crie um Static Site ligado a esse repositório.
4. O painel admin ficará em /admin.html.

IMPORTANTE:
O painel ainda não tem autenticação. Antes de deixar o painel público, vamos adicionar login no backend.
